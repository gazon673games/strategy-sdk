# Strategy SDK

Переносимые Python-контракты для исполнения пользовательских алгоритмов в исторических
и других приложениях-хостах. Python 3.10+, без обязательных runtime-зависимостей.

Публичный пакет содержит типы баров, снимков счёта, решений и исполнений; проверки
причинности, параметров и состояния; арифметику Decimal, индикаторы и расчёт размеров.
SDK не загружает историю и не отправляет заявки.

## Установка и проверка

```sh
uv sync --extra dev --extra timezones
uv run python -m unittest discover -s tests -v
uv run ruff check .
uv run ruff format --check .
uv build
```

## Собственные исходники

Алгоритмы хранятся локально, вне публичного пакета. Пользовательские файлы в
`src/strategy_sdk/catalog/` исключены из Git и сборок. Публичный каталог содержит
только `empty`: техническую заготовку, которая возвращает HOLD и не создаёт сигналов.
Контракт описан в [руководстве интеграции](docs/host_integration.md).

`load_file_strategy(path)` загружает доверенный файл и фиксирует его зависимости.
Снимки состояния и подтверждённые исполнения передаёт приложение-хост. Код пользователя
доверенный; загрузчик не является песочницей. Доступ к будущим барам запрещён.

## Редактор

В `editor/` находятся Python-редактор и представления параметров Blockly/LiteGraph.
Они работают с локальными файлами. Готовые торговые алгоритмы не распространяются.
См. [запуск редактора](docs/visual_editor.md).

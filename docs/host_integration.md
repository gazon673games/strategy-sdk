# Интеграция с приложением-хостом

Хост передаёт завершённые бары, инструмент, фактическую позицию, снимок счёта и состояние.
Файл задаёт STRATEGY_METADATA, data_requirements(params) и generate_signal(ctx, params).
Необязательные initialize и on_fill получают явное состояние и подтверждённые исполнения.

Для загрузки используйте `strategy_sdk.load_file_strategy(path)`. Параметры проверяются
до исполнения; входные снимки и результаты используют публичный контракт версии 1.
HOLD сохраняет позицию, TARGET задаёт целевую позицию, SKIP пропускает решение.
TARGET с нулём закрывает позицию. Ошибка данных не становится автоматически TARGET 0.

Хост отвечает за проверенные данные, расписание, исполнение, комиссии, маржу и учёт.
Пользовательские исходники, пресеты, результаты и их снимки остаются локальными.

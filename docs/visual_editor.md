# Локальный редактор

```sh
uv sync --extra dev --extra timezones
cd editor
npm ci
npm test
npm run build
cd ..
uv run python tools/run_editor.py
```

Редактор слушает loopback. Python-режим позволяет открыть собственный файл, проверить
контракт и сохранить изменения с контролем ревизии и резервной копией в `.history`.
Blockly и LiteGraph показывают параметры выбранного локального модуля. Произвольные
Python-правила редактируются в текстовом режиме.

Публичная заготовка не содержит торговых условий. Собственные файлы каталога,
пресеты и результаты не входят в публичный репозиторий или дистрибутив SDK.
